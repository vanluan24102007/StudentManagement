# \# Student Management System

# 

# A console-based Student Management System developed using C++ and Object-Oriented Programming (OOP).

# 

# \## 1. Project Overview

# 

# This project is designed to manage student information through a simple command-line interface. It applies fundamental OOP concepts and basic file handling in C++.

# 

# \## 2. Features

# 

# \- Add new students

# \- Display all students

# \- Search students by ID

# \- Search students by name

# \- Update student information

# \- Delete students

# \- Sort students by name

# \- Sort students by average score (ascending/descending)

# \- Display statistics (total students, average, highest and lowest scores)

# \- Validate user input

# \- Save student data to a text file

# \- Load student data from a text file

# 

# \## 3. Technologies

# 

# \- \*\*Language:\*\* C++

# \- \*\*IDE:\*\* Visual Studio

# \- \*\*Concepts:\*\* Object-Oriented Programming (OOP), STL, File Handling

# \- \*\*Version Control:\*\* Git and GitHub

# \## 5. How to Run

# 

# 1\. Clone this repository.

# 2\. Open the solution file in Visual Studio.

# 3\. Select the Debug x64 configuration.

# 4\. Build the solution.

# 5\. Run the application.

#

#
